# skill 目录

每个产品 skill 在本目录下有自己的 `SKILL.md`、参考文件和脚本。当前 `maa-help` 提供偏好设置，`maa-account` 提供本地识别结果导入；实现与临时原生安装已验证，真实模型基线仍未建立并阻止发布。其他入口未交付。唯一共享工具随 `maa-help/scripts/` 安装，其他入口从同版本的相邻目录复用。原生安装与共享载荷的验收见 [宿主说明](../docs/hosts.md)、[04 工单](../docs/issues/04-install-help-preferences.md)和 [11 工单](../docs/issues/11-maa-account-snapshot.md)。
