# maa-help

只用文字回答，用用户这句话的语言回复。本 skill 不读取设置文件，不运行脚本，不写文件，也不改 MAA。

按用户目标说明入口：

| 用户目标 | 对应 skill |
| --- | --- |
| 接入已有 Windows GUI MAA、设置语言／私有目录、测试本机模拟器 adb 连接 | maa-setup |
| 下载 MAA／模拟器／adb、补齐缺失程序 | maa-setup（当前给官方安装入口，自动下载为后续能力） |
| 读取 MAA 本地识别结果、保存账号快照 | maa-account |
| 查询单干员培养的原始成本、不加工的已知库存差额 | maa-account |
| 比较明确培养目标共用库存、加工与材料券后的缺口，查看不加工对照 | maa-account（只给建议，不加工或兑换） |
| 按干员或房间查询已持有干员的基建技能、后续解锁和条件 | maa-account |
| 在 NGA 检索、读帖，取得带作者、日期和出处的社区资料 | maa-account（只读；需要你先在自己的终端设置 NGA 凭据） |
| 按玩法优先级排培养顺序：每一步的花费、库存够到哪一步、带依据的推荐理由 | maa-account（培养建议报告；默认经独立审查，当次说一句可以跳过并标「未审查」；逐项批准，批准不等于执行） |
| 基建排班建议 | maa-account（后续能力） |
| 修改已批准的普通队列、提醒和现有定时槽 | maa-daily |
| 准备指定关卡作业、基建排班或专精排程 | maa-daily（后续能力） |
| 设置 NGA、森空岛账号或 B 站（实验性）凭据，查看凭据是否设置、是否过期 | maa-setup（用户在自己的终端运行输入脚本，不在对话里贴凭据）；状态也可由 maa-doctor 检查 |
| 检查配置和写入锁、按点名批准核对遗留写入或恢复已记录字段 | maa-doctor |
| 检查连接、安装、版本或 MAA 自身报错 | maa-doctor（后续能力） |
| 解释入口、功能和安装方式 | maa-help |

当前提供 maa-help、maa-setup、maa-account、maa-daily、maa-doctor 和共享脚本目录 maa-core。setup 每次检查已有环境，首次设置语言和私有目录，测试用户选定的本机 adb 连接；保存连接设置仍需统一写入器和 MAA 关闭时的单独确认。账号识别由用户在 MAA 界面启动，account 读取本地结果并保存快照。成本查询按单干员明确的精英化、等级、技能、专精或模组目标计算；不加工差额只扣已知库存，缺失练度或库存保持待核。基建技能查询列出技能与条件，不生成排班建议，也不把技能文字的百分比当成最终收益。

加工与材料券缺口查询可让多个明确目标共用一次库存，比较可行加工、券直接覆盖和券换下级材料后加工的建议顺序、费用及不加工方案。只计已确认的库存、条件与有效券；缺事实保持待核，不要求用户猜公开表原码。结果是所选方案，不承诺经济最优，也不兑换、加工或操作设备。

培养建议报告的数字来自同一份缺口计算，依据带作者、日期和出处，事实和推断分开；account 不写 MAA 配置、不执行培养，只有你批准的条目才交给 daily。森空岛读取与基建排班建议仍未交付；NGA 凭据已用于 account 的只读检索和读帖，森空岛账号和 B 站（实验性）凭据目前只能设置和检查状态，用到它们的读取是后续能力。daily 当前只维护已有配置；doctor 当前核对配置和锁并报告凭据状态，损坏配置或无法证明的结果保留证据交用户处理。提供入口不代表用户已经安装；尚未装好时说明先安装同版 core 和对应入口，接入问题可交 setup 检查，缺失程序按官方入口自行安装，自动下载为后续能力。

用户想改回复语言、私有目录，或者想让某句偏好被记住时，说明可交给已交付的 maa-account 通过 maa-core 的偏好脚本记录，本 skill 不代为写入。

所有入口共同的边界：不碰源石、抽卡、礼包、付费、登录，不点游戏、不操作设备；任何偏好都不能放开这一条。

用户问安装、更新，或者某个入口提示找不到 maa-core 时，读取 [宿主说明](references/hosts.md) 并给出对应宿主的命令。
