# maa-help

只用文字回答，用用户这句话的语言回复。本 skill 不读取设置文件，不运行脚本，不写文件，也不改 MAA。

按用户目标说明入口：

| 用户目标 | 对应 skill |
| --- | --- |
| 接入已有 Windows GUI MAA、设置语言／私有目录、测试本机模拟器 adb 连接 | maa-setup |
| 下载 MAA／模拟器／adb／Node、补齐缺失程序 | maa-setup（先展示官方下载方案，用户确认这一份方案后才下载） |
| 读取 MAA 本地识别结果、保存账号快照 | maa-account |
| 不开模拟器从森空岛只读读取账号快照，对比 MAA 与森空岛两份快照 | maa-account（要先由用户自己在终端设置森空岛 token） |
| 查询单干员培养的原始成本、不加工的已知库存差额 | maa-account |
| 比较明确培养目标共用库存、加工与材料券后的缺口，查看不加工对照 | maa-account（只给建议，不加工或兑换） |
| 按干员或房间查询已持有干员的基建技能、后续解锁和条件 | maa-account |
| 在 NGA 检索、读帖，取得带作者、日期和出处的社区资料 | maa-account（只读；需要你先在自己的终端设置 NGA 凭据） |
| 读你给出链接的森空岛社区帖子 | maa-account（只读；用你自己在终端设置的森空岛 token，和账号快照同一个 token；没设置时它会告诉你怎么设置，不在对话里要 token；没有森空岛社区检索，不发帖、点赞或评论） |
| 读你给出链接的 B 站视频信息和字幕（实验性，随时可能失效） | maa-account（实验性、只读；字幕需要你先在自己的终端设置 B 站 SESSDATA；没有 B 站检索） |
| 按玩法优先级排培养顺序：每一步的花费、库存够到哪一步、带依据的推荐理由 | maa-account（培养建议报告；默认经独立审查，当次说一句可以跳过并标「未审查」；逐项批准，批准不等于执行） |
| 按自己的布局、名册和目标生成基建排班建议，检查容量、心情和 15 项验收门 | maa-account（基建建议报告；审查、跳过和逐项批准同培养报告；只在私有目录写排班文件） |
| 修改已批准的普通队列、提醒和现有定时槽 | maa-daily |
| 把 account 基建报告里批准的排班写进 MAA：写入前重新检查 15 项验收门，未核实的项由你决定 | maa-daily（只改所选基建任务的自定义排班设置，指向私有目录里批准的排班副本；经统一写入器在关停 MAA 后写入；不点游戏，换班由 MAA 运行时进行） |
| 准备指定关卡作业或专精排程 | maa-daily（后续能力） |
| 设置 NGA、森空岛账号或 B 站（实验性）凭据，查看凭据是否设置、是否过期 | maa-setup（用户在自己的终端运行输入脚本，不在对话里贴凭据）；状态也可由 maa-doctor 检查 |
| 检查配置和写入锁、按点名批准核对遗留写入或恢复已记录字段 | maa-doctor |
| 检查安装、连接、远程控制、私有文件、版本、skill 更新和目录联接，分析 MAA 运行为什么失败，MAA 自身问题的转介 | maa-doctor |
| 解释入口、功能和安装方式 | maa-help |

当前提供 maa-help、maa-setup、maa-account、maa-daily、maa-doctor 和共享脚本目录 maa-core。setup 每次检查已有环境，首次设置语言和私有目录，测试用户选定的本机 adb 连接；保存连接设置仍需统一写入器和 MAA 关闭时的单独确认。账号识别由用户在 MAA 界面启动，account 读取本地结果并保存快照。成本查询按单干员明确的精英化、等级、技能、专精或模组目标计算；不加工差额只扣已知库存，缺失练度或库存保持待核。基建技能查询列出技能与条件，不把技能文字的百分比当成最终收益。

加工与材料券缺口查询可让多个明确目标共用一次库存，比较可行加工、券直接覆盖和券换下级材料后加工的建议顺序、费用及不加工方案。只计已确认的库存、条件与有效券；缺事实保持待核，不要求用户猜公开表原码。结果是所选方案，不承诺经济最优，也不兑换、加工或操作设备。

培养建议报告的数字来自同一份缺口计算，依据带作者、日期和出处，事实和推断分开；account 不写 MAA 配置、不执行培养，只有你批准的条目才交给 daily。基建建议报告按你说的布局、班次和目标生成排班文件并检查 15 项验收门，有不通过的项就不能批准，未核实的项单独列出由你决定；account 不写 MAA 配置；批准过的排班由 daily 应用，写入前按当前快照和数据重新检查，报告或快照在批准后变了要重新出报告并批准，完成后只说明写入的设置和备份，不说 MAA 已经按时间段换好班。森空岛账号读取只读：account 用用户自己设置的 token 读取并另存森空岛快照，不签到、不发帖，也不替用户登录；两份快照并列保留、可对比，不合并。截至 2026-11-13 没有找到鹰角对第三方调用森空岛接口的公开表态，森空岛数据比游戏内滞后多久也没有测过。社区调研目前有 NGA（用你自己设置的凭据）和实验性的 B 站视频读取（字幕用你自己设置的 SESSDATA），都只读。森空岛社区帖子：account 用你自己设置的森空岛 token 只读读取你给出链接的帖子，不检索、不发帖、不点赞、不评论。NGA 凭据已用于 account 的只读检索和读帖，森空岛账号凭据用于只读账号快照和读你给出链接的森空岛社区帖子，B 站（实验性）SESSDATA 只用于读取字幕。daily 当前只维护已有配置，并应用已批准的基建排班；doctor 检查安装、连接、配置、写入锁、凭据状态、私有文件、skill 版本和目录联接，读 MAA 日志判断运行失败的原因，MAA 自身问题只给官方入口和脱敏摘要；损坏配置或无法证明的结果保留证据交用户处理。提供入口不代表用户已经安装；尚未装好时说明先安装同版 core 和对应入口，接入问题可交 setup 检查，缺失程序由 setup 先展示官方下载方案，用户确认后才下载，安装程序、登录和界面步骤由用户自己完成。

用户想改回复语言、私有目录，或者想让某句偏好被记住时，说明可交给已交付的 maa-account 通过 maa-core 的偏好脚本记录，本 skill 不代为写入。

所有入口共同的边界：不碰源石、抽卡、礼包、付费、登录，不点游戏、不操作设备；任何偏好都不能放开这一条。

用户问安装、更新，或者某个入口提示找不到 maa-core 时，读取 [宿主说明](references/hosts.md) 并给出对应宿主的命令。
