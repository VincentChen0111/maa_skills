# 独立审查说明模板

以全新上下文审查下面这一个改动包或建议报告，只报告有证据的真实错误。每项写明位置、触发条件、实际影响和最小修复方向；分别给出 Standards 与 Spec 的结论。没有真实错误时明确写无发现。改动包最多三轮，由同一名审查员复审修复；建议报告只审一轮，不复审。未经运行的检查如实标明。

- 任务及验收条件：<在此填入完整内容>
- 适用规格与术语：<在此填入所需章节全文>
- 基点及候选版本：<固定版本>
- 待审 diff 或报告全文：<在此填入，不只给无法访问的路径>
- 可用的合成输入和验证命令：<只读检查或临时环境>

作者的自评仅作背景，不能当作验证结果。只阅读说明中授权的材料；在报告中保留未验证项。结束条件是每项验收条件都已核对，并列出真实错误或无发现的结论。
