# 森空岛账号快照

不开模拟器时，maa-account 可以用你自己设置的森空岛 token 读取账号数据，保存一份带读取时间、标明来源的账号快照。这个功能可选；不用它，MAA 本地识别照常可用。

## 使用前请了解

1. 截至 2026-11-13，没有找到鹰角网络对第三方调用森空岛接口的公开表态。是否使用，由你自己决定。
2. 森空岛数据比游戏内实际状态滞后多久，没有测过。快照里的读取时间是本工具从森空岛读取的时间，不等于游戏内的数据时间。

每次读取的结果里也会写这两点。

## 怎么用

1. 按[凭据说明](credentials.md)在你自己的终端里粘贴 token。agent 不会向你要 token 或密码，也不会替你登录。
2. 对 agent 说要从森空岛读取账号数据。只看时它运行 `inspect`，不保存；你要保存时它运行 `import`。
3. 想知道 MAA 识别和森空岛是否一致时，让 agent 对比两份快照。

## 读什么、不做什么

只读：用 token 换取访问凭证、给请求签名、过期时刷新都在本机脚本里完成，只请求绑定角色、玩家信息和养成数据。不签到、不发帖、不点赞、不付费，不做任何账号写操作。token、访问凭证、角色号和昵称都不会出现在对话、快照、记录或错误信息里。

快照里有：

- 干员的稀有度、精英化、等级、潜能，以及技能等级、专精和模组（MAA 识别给不出这三项）；
- 养成接口返回的物品数量；龙门币只在返回了物品 `4001` 时才有；
- 基建房间、驻员和心情（原始值及其记录时间）。

没有返回的项目保持未知，不当成零。理智药等药剂、凭证和各类券、逐关通关状态目前没有找到来源，快照里明确写成「无来源」。账号的绑定角色有多个且没有默认角色时，请先在森空岛 App 里设好默认角色。

## 保存在哪里

森空岛快照保存在你的私有目录，文件名 `account-snapshot-skland.json`；MAA 识别的快照仍是 `account-snapshot.json`。两份并列保留，对比时列出差异和两边的时间，不会合并成一份。MAA 配置不会被改动。

## 读取失败时

读取失败时不会写新快照，已有的森空岛快照原样保留，也不会被当成这次读到的数据。结果会说明原因和下一步：

- token 未设置、已知过期或无法读取：按[凭据说明](credentials.md)重新粘贴。只有森空岛在用 token 换取访问凭证时明确拒绝，才记为已知过期。
- 签名被拒：这次读取里 token 已经被接受，但请求签名仍被拒绝，所以不算过期，不用重新粘贴。请检查电脑的系统时间和时区；时间正确仍失败时，接口可能变了，请[报告问题](https://github.com/VincentChen0111/maa_skills/issues)。
- 网络失败、限流或风控：凭据状态不变，稍后再试；工具不会自动反复重试。
- 回复格式变了（例如玩家信息里没有干员，或者干员列表的结构不对）：工具不采用这次结果，不写快照，请[报告问题](https://github.com/VincentChen0111/maa_skills/issues)。

干员、仓库、基建三部分，只有完整读到才算读到。请求失败、回复结构不对、列表为空、少了某一部分或条目里少了字段，都算没读到。只读到一部分时（例如干员读到了，仓库为空或请求失败）：

- 已经有森空岛快照时，不用这次不完整的结果替换它，旧快照原样保留；结果会列出没读到的部分和建议：请求失败时稍后再试；回复内容有问题（结构不对、为空或缺少部分）时说明接口可能变了，请报告问题，重试不会好。
- 还没有森空岛快照时，保存这第一份：有内容的部分标为部分读取，没有内容的部分清空并标为不可用（请求失败）或无效，原因都写明；之后完整读取时会替换它。

接口和字段的核对记录见[森空岛接口来源](skland-account-sources.md)。
