# 凭据说明

部分功能要用到你自己的登录凭据：NGA 调研、读取你的森空岛账号数据，以及实验性的 B 站调研。凭据只由你在自己电脑的终端里输入。agent 不会请你把凭据贴到对话里，也不会替你登录；它只能检查凭据有没有设置、是否已知过期，看不到值。

这些功能都是可选的。不设置凭据，MAA 接入、日常配置和 MAA 本地识别照常可用。

## 怎么设置

1. 先用 maa-setup 完成首次设置（语言和私有目录）。
2. 让 agent 给出命令，或者自己在已安装的 `maa-core` 目录里找到 `scripts/credentials.ts`。打开你自己的终端窗口（PowerShell 或 Windows Terminal），运行：

   ```text
   node <maa-core 目录>\scripts\credentials.ts input skland
   ```

   把 `skland` 换成 `nga` 或 `bilibili` 设置另外两项。加 `--language en` 可以看英文说明。
3. 看完说明，输入 `y` 回车，再粘贴值回车。为了不在屏幕和终端记录里留下内容，两次输入都不显示；按 Ctrl+C 随时取消，取消或失败时原来的设置不变。

不要把值写在命令行参数里，也不要让 agent 替你运行这条命令：命令会检查自己是否运行在你的终端里，不是就拒绝。

各项要输入的内容：

| 命令参数 | 要输入的值 |
| --- | --- |
| `skland` | 你自己取得的森空岛（鹰角网络通行证）token |
| `nga` | 在已登录 NGA 的浏览器里，Cookie 请求头的值 |
| `bilibili` | 在已登录 B 站的浏览器里，名为 `SESSDATA` 的 Cookie 值 |

不会要求任何密码。

## 森空岛：粘贴前请了解

1. 截至 2026-11-13，没有找到鹰角网络对第三方调用森空岛接口的公开表态。是否使用，由你自己决定。
2. 这个 token 只用来读取账号数据（干员、仓库、基建等），不用于任何写入、签到或修改；读取的范围见[森空岛账号快照](skland-account.md)。

森空岛账号凭据只有一种设置方式：你自己取得 token，在上面的本地脚本里粘贴。本项目不提供账号密码登录，不通过浏览器或内嵌网页抓取登录请求，也不保存密码用于过期后自动重新登录。token 过期后，重新运行同一条命令粘贴新的 token。

森空岛社区公开内容的调研只读公开网页，不使用这个 token，两者互不相干。

## B 站：实验性

B 站相关功能是实验性的，可以用，但不保证稳定，接口变化后可能随时失效，请不要依赖它。只用于只读调研，不发评论、不点赞。

## 保存在哪里、怎么撤销

凭据保存在你设置的私有目录下的 `credentials` 文件夹，不进仓库，也不写进设置文件。值按 Windows 当前用户加密（DPAPI），只有你这个 Windows 用户在这台电脑上能解开；复制到别的电脑或别的用户下无法使用，需要重新输入。

想撤销某一项时，删除 `credentials` 文件夹里对应的 `<名称>.json` 和 `<名称>.status.json`，例如 `skland.json` 和 `skland.status.json`。如果你怀疑凭据已经泄露，到对应网站退出登录或修改账号安全设置，让旧凭据失效。

## 状态的含义

agent 和 `maa-doctor` 报告的状态：

- 未设置：没有保存，需要对应功能时再设置。
- 尚未验证：已经保存，但还没有用它实际读取过，不知道是否有效。保存后的第一次实际读取会给出结果。
- 可用：最近一次实际读取成功；下一次读取前仍可能过期。
- 已知过期：最近一次读取被拒绝，或者已知的到期时间已过。重新运行输入命令即可。
- 无法读取：保存的记录损坏，或者当前 Windows 用户解不开。重新运行输入命令即可。

检查本身不联网，也不会解开保存的值。

## 如果不小心把值贴进了对话

agent 不会保存或使用对话里的值。对话内容可能留在聊天记录里，建议到对应网站退出登录或换新，再用本地命令输入新的值。
