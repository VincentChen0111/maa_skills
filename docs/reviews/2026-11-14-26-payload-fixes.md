## Issue #91 与协调者改正

包 H 第一轮审查的 P2：真实模型在 Windows 上用 PowerShell 5.1 管道把审查说明交给 `codex exec`，中文变成 `?`。审查员可能照样回复「没有意见」，报告就会在没被审查的情况下记成「已审查」。

修法：
- Windows 上把说明路径放进环境变量，用 `cmd /d /c` 加 `<` 重定向传入；POSIX 直接重定向；
- 明确不许用任何 PowerShell 管道；
- 回复看得出审查员没读到说明时，记 `fail`。

照原说明直接把路径嵌进 `cmd` 命令，从 PowerShell 5.1 运行会找不到文件，所以改用环境变量。

协调者改正 `030bd17`：规格里 doctor 检查原写「检查只读」，改成「不改 MAA 配置、锁和设备，只把脱敏结果原子保存为 `doctor-latest.json`」。
