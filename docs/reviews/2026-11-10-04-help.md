# 04 maa-help 与偏好设置审查

日期：2026-11-10。基点：`ecc7325`（03 已交付）。范围为 maa-help、唯一共享偏好脚本、安装载荷、场景和评测输入扩展、测试、说明及来源表。

## 第一轮

独立审查员 `review_04`，基于规格、工单和完整候选 diff，结论为需要修正两项真实错误：

1. 语言场景 `expectedCalls` 为空，直接改写设置和原话文件也会得到 pass 8/8。接受：公开 grader 失败测试复现，隔离 Node 观察器现记录原生目录内偏好脚本的实际入口、动作、退出码和进程号；场景同时要求成功调用及实际文件变化。直接文件写入仍会被发现，但不能满足脚本调用要求。观察器只用于评测，不随产品安装，也不依据回复措辞评分。
2. 目录联接修正对 `argv[1]` 无条件执行 realpath，导致 `node --input-type=module -` 导入导出函数时报 ENOENT。接受：标准输入导入失败测试复现，入口判断现跳过标准输入并容忍无文件入口；真实目录联接测试仍通过。

修正后相关 16 项测试和类型检查通过。首轮提到的默认沙箱 rename 失败为环境权限限制，同一真实临时目录测试提升权限后通过。

第二轮结论：离线实现审查通过；其后远程 Windows CI 发现短路径入口问题，进入第三轮。

同一独立审查员最终复核：Standards 0 项，Spec 0 项新增。独立复跑相关 9/9 测试通过且无跳过，包括短路径、目录联接、标准输入导入及直接写入拒绝；未发现临时清理会删除 clone 目标的问题。作者在原短路径环境复跑完整离线入口 28/28、类型及隐私检查通过。

最终结论：本包共三轮，离线实现审查通过，交付为[草稿 PR #32](https://github.com/VincentChen0111/maa_skills/pull/32)。远程 CI 与双宿主验收的最终状态见验证记录。本结论不等于工单 04 全部完成，不解除后续工单依赖。
