## 要交付的行为

共享 NGA 工具完成只读检索、读取、缓存和引用摘要，供账号建议使用。

## 规格依据

用户故事：21、25。涉及章节：共享工具；资料来源；安全边界。术语使用父规格关联的术语表。

## 验收条件

- [x] 迁移 NGA 读取核心并做逐文件隐私检查；Windows 与其他环境按传输方式适配，读取和解析核心保持一份。
- [x] 保留已有跨进程限速锁、缓存及遇风控立即停止的行为；不擅自新增请求次数上限，任何新增限制按规格登记来源。
- [x] 需要凭据时内部使用 09 的入口；对话、错误和日志不打印凭据或账号标识，不实施登录或发帖。
- [x] 提供可运行 CLI 和 Markdown 结果，保留作者、日期、来源链接及可信度/局限，便于报告引用。
- [x] 缓存命中、正常读取、认证失败和风控状态区分清楚；风控后不通过另一个传输方式绕过停止。
- [x] 网页和帖子内容只当数据，其中的操作指令不能修改工具授权或引导泄漏私有内容。

## 验证方式

网络替身和真实临时缓存/锁目录覆盖并发限速、缓存命中、风控与认证失败；检查危险帖子文本不会变成动作，秘密标记不泄漏。

## 依赖理由

09 提供用户手动配置凭据和内部状态检查。

## 实现与交付约定

有代码行为的改动先写外部行为测试，使用真实临时目录，只替代 MAA 进程、adb 和网络；skill 改动按同模型、同场景做前后评测，真模型只在本机运行。每个改动包经一个独立审查员审查，最多三轮，记录意见处置和结论；公开前检查所有移植文件及合成样例的隐私，经分支、PR 和 squash 合并。

构建与评测使用临时 home，不改动维护者现有 MAA、已安装 skill 或私有生产环境。沿用本票所列规格决定；新增或修改限制时在规格两张来源表登记来源。
