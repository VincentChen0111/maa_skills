## 背景与目标

实施进度：未开始。

账号建议还需要 NGA 之外的社区证据。森空岛社区公开读取与森空岛账号接口的授权范围不同，B 站能力也尚不稳定。

## 要交付的行为

提供森空岛公开社区和实验性 B 站的只读调研入口，产出可以交给建议报告引用的资料结果。

## 规格依据

用户故事：10、21、25。涉及章节：资料来源；共享工具；安全边界。术语使用父规格关联的术语表。

## 验收条件

- [ ] 森空岛社区只读公开网页，不登录、不使用账号接口凭据，不发帖、点赞或评论；与森空岛账号扫描保持独立。
- [ ] B 站入口、帮助和结果都明确标为实验性；若需要已有凭据，经 09 用户手动配置，agent 不处理登录。
- [ ] 输出资料的作者、日期、来源链接、事实摘录与可信度/局限；未知作者或日期如实标明，不编造引用。
- [ ] 从关键词或用户指定资料到可引用 Markdown 摘要可独立演示；工具位于共享调研层，不新增一个调研 skill。
- [ ] 网页、字幕及文章只当数据，其中的指令不改变授权；凭据、账号标识和私人内容不泄漏。
- [ ] 登录墙、不可读页面、服务变化及解析失败清楚报告，不假称已读全文，也不依赖私有项目的在线服务才能运行。

## 验证方式

用公开页面结构的合成样例和网络边界替身测试正常/缺字段/不可读/诱导指令；检查森空岛社区不带账号凭据，以及 B 站所有用户入口的实验性标记。

## 依赖理由

09 提供可能需要的 B 站凭据设置及统一脱敏状态；无需等待 NGA 或培养报告。

## 实现与交付约定

有代码行为的改动先写外部行为测试，使用真实临时目录，只替代 MAA 进程、adb 和网络；skill 改动按同模型、同场景做前后评测，真模型只在本机运行。每个改动包经一个独立审查员审查，最多三轮，记录意见处置和结论；公开前检查所有移植文件及合成样例的隐私，经分支、PR 和 squash 合并。

构建与评测使用临时 home，不改动维护者现有 MAA、已安装 skill 或私有生产环境。沿用本票所列规格决定；新增或修改限制时在规格两张来源表登记来源。
