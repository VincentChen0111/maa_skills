## 验收条件

- [x] 移植成本计算及其数据构建的通用实现，解除原私有项目存储/运行环境耦合；逐文件检查代码、注释和样例，替换真实账号基线。
- [x] 读取 11 的快照与明确目标，按名称找到干员；当前练度或目标不完整时标出待核输入，不当成零成本或已满足。
- [x] 覆盖精英化、专精各级及模组各级的逐步材料和龙门币成本，总计可追溯到步骤；CLI 与 Markdown 表达同一结果。
- [x] 运行时从明确注明的公开游戏数据镜像固定提交取数，不打包游戏数据；一图流材料价值和企鹅物流掉率按需读取并署名，不打包其数据。
- [x] 提供原始成本及不加工的查询方式；加工与材料凭证的缺口决策由 14 补齐，本票不假称已经扣除。
- [x] arkntools 只交叉核对成本，差异列出而不自动修正；数据来源、版本和不确定项出现在结果中。
- [x] 共享计算仅保留一份可被 CLI 和其他项目引用的实现，不修改原私有项目的生产副本。

## 验证方式

用合成数据和网络样例先测逐级差分、当前等于目标、缺字段、名称歧义与来源冲突；实际执行 CLI 检查数值和 Markdown，测试不取真实游戏数据或账号。
