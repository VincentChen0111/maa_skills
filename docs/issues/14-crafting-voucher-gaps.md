## 要交付的行为

在成本查询中加入库存扣减、加工与材料凭证的比较，给出从原始需求到最终缺口的解释。

## 规格依据

用户故事：18、19。涉及章节：共享工具；账号快照与建议报告；资料来源。术语使用父规格关联的术语表。

## 验收条件

- [x] 按目标的逐步成本和账号库存计算缺口，输出原始需求、已有材料、可加工补足、凭证可覆盖及仍缺部分。
- [x] 沿用移植成本工具已有的配方与可用条件，清楚展示缺失条件；未知库存或账号进度不被当成已满足。
- [x] 支持开启加工与 --no-craft 的结果比较；多个目标共用库存时不重复分配同一份材料，材料和龙门币消耗计入步骤。
- [x] 材料凭证只纳入可覆盖缺口的计算和建议，不自动兑换或消耗；使用规则及来源在输出中可追溯。
- [x] 保留按干员名称查询、CLI 和 Markdown 输出，逐步成本与总量可以互相核对。
- [x] 处理数据源不一致时列出差异，arkntools 仍只交叉核对；推断和已核实计算输入明确区分。

## 验证方式

通过零缺口、只靠加工可补足、凭证部分覆盖、多个目标竞争材料、缺少输入及禁止加工等合成场景验证守恒和不重复扣减。
